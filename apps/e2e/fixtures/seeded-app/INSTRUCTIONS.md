# Task

This is a Vite + React + TypeScript app. Your job:

1. Run `npm install` (the sandbox has network access for this task).
2. Open `src/App.tsx`. It doesn't compile yet — read the `TODO` comment at
   the top and add the missing `count` state so it does.
3. Run `npm run build` and make sure it exits successfully (no TypeScript or
   build errors). If it fails, fix the code and run it again.

Do not modify `package.json`, `vite.config.ts`, `index.html`, or
`src/main.tsx` — they're already correct.
